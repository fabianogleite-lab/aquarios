O QUE VOCÊ PRECISA FAZER
═══════════════════════════════════════════════════════════════════════════════

⚠️ IMEDIATO (Dia 1-2)
  1. Editar backend/.env com seus valores
     DATABASE_URL, JWT_SECRET, ENCRYPTION_KEY, ANTHROPIC_API_KEY
  2. Criar database PostgreSQL
     createdb aquarios_v2
  3. Migrar schema
     psql aquarios_v2 < backend/schema_v2_0000.sql
  4. Seed data
     npm run seed:database
  5. Start backend
     npm run dev

⚠️ CURTO PRAZO (Dia 3-5)
  1. Criar mobile/assets/
     - icon.png (512x512)
     - splash.png (1080x1920)
     - adaptive-icon.png
  2. Implementar mobile screens (6 screens)
     LoginScreen, DashboardScreen, DiarioScreen, etc
  3. Implementar mobile services
     API client, Auth manager, Storage handler
  4. Build APK
     eas build --platform android --type apk

⚠️ MÉDIO PRAZO (Dia 6-7)
  1. Upload APK/AAB to Play Store
  2. Invite beta testers
  3. Monitor crashes + performance
