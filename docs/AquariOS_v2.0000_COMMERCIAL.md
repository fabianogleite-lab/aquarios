## 1.5 FAQ Responses (20+ Q&A)

### 1. O que é IVI Score?

IVI = Índice de Vitalidade Integrada.

Métrica única que combina:
- **Bio (40%)**: Nutrição, exercício, sono, sinais vitais
- **Mental (35%)**: Stress, foco, motivação, saúde mental
- **Spirit (25%)**: Propósito, comunidade, tradição, práticas

Diferente de apps que só rastreiam passos ou calorias. AquariOS vê você inteiro.

---

### 2. Como AquariOS sabe o que comi?

**Foto + IA Vision** (Google Cloud + USDA database):

1. Você tira foto da refeição
2. IA extrai: ingredientes, porções, macros, micros
3. Compara com banco de 500k alimentos (Brasil + internacional)
4. Retorna: calorias, proteína, fibra, índices glicêmicos

**Acurácia**: 90%+ (validada contra pesagem real)

---

### 3. Preciso de wearable?

**Não.**

Mas se tiver:
- Apple Watch → Sincroniza automaticamente (frequência cardíaca, sono)
- Fitbit → Sincroniza via API
- Sem wearable → Validamos via foto + voz + manual

---

### 4. Como a IA entende meu contexto?

**ProteOS** (módulo IA):

1. Você fala para um áudio (voz 30-60s)
2. IA transcreve + analisa sentimento + contexto
3. Conhece sua tradição (Católico, Budista, etc)
4. Sabe sua rotina (home office, executivo, atleta)
5. Sugere ações personalizadas (ex: "stress alto → meditação")

---

### 5. Vocês vendem meus dados?

**Nunca.**

Somos LGPD-compliant:
- Dados são **seus** (você controla)
- Nunca vendemos a 3ºs
- Benefício: Pesquisa anônima + agregada (melhoramos IA)
- Você vê exatamente quem acessa seus dados

---

### 6. Posso comer fora?

**Claro!**

AquariOS não julga. Entende contexto:
- Refeição em restaurante? Anota.
- Chocolate no domingo? Tudo bem.
- IVI Score reflete escolhas, não culpa.

Mentorias ajudam a fazer escolhas **melhores**, não perfeitas.

---

### 7. Quanto custa realmente?

**Tiers Brasil**:
- **FREE**: R$ 0/mês (teste 7 dias completo)
- **COMPLETO**: R$ 299/mês ⭐ (análise completa + 2 mentorias)
- **ELITE**: R$ 699/mês (coach 1:1 semanal + Daimon)

Sem surpresas. Sem taxa oculta.

---

### 8. Posso cancelar quando quiser?

**Sim.**

- FREE → COMPLETO: Cancela na semana 1, sem problema.
- Qualquer tier: 1 clique, sem perguntas, sem penalidade.
- Dados continuam seus (você baixa CSV).

---

### 9. Como funciona a mentoria?

**COMPLETO**: 2 mentorias ao vivo/mês (30 min cada)
- Videoconferência Zoom
- Nutricionista + psicólogo disponível
- Você escolhe foco (nutrição, stress, sono, etc)

**ELITE**: 1 mentoria/semana + chat assíncrono 24h
- Coach pessoal (não rotativo)
- Aprende sua história, seus triggers
- Agenda flexível

---

### 10. Funciona para qualquer tradição?

**Sim.**

AquariOS entende:
- 13+ tradições filosóficas (Catolicismo, Budismo, Tarot, Islamismo, etc)
- Comunidades por tradição
- Recursos específicos (santos, sutras, mantras, etc)
- Mentores que entendem sua fé

## C. Unit Economics & Formulas

### LTV (Lifetime Value)

```
LTV = ARPU × Lifetime (meses) × Retenção Média × Margin

Exemplo Brasil (COMPLETO):
ARPU = R$ 299
Lifetime = 24 meses (2 anos alvo)
Retenção = 0.65 (65% average)
Margin = 0.70 (30% costs)

LTV = 299 × 24 × 0.65 × 0.70 = R$ 3.299
```

### CAC (Customer Acquisition Cost)

```
CAC = Marketing Spend / New Customers Acquired

Alvo Fase 1 (orgânico + embaixadores):
CAC < R$ 100

Alvo Fase 2 (mix orgânico + pago):
CAC < R$ 200

Máximo aceitável:
CAC < LTV / 3 = R$ 1.100 (no nosso caso)
```

### LTV:CAC Ratio

```
LTV:CAC = LTV / CAC

Alvo: > 3:1 (viável)
Excelente: > 10:1 (escalável)

Exemplo Brasil:
LTV:CAC = R$ 3.299 / R$ 100 = 33:1 ✅ (excelente)
```

### Payback Period

```
Payback = CAC / Monthly MRR per User

Exemplo:
Payback = R$ 100 / R$ 299 = 0.33 meses (~1 semana) ✅
```

### Churn Rate

```
Monthly Churn = (Lost Users / Start Users) × 100

Alvo Fase 1: < 20% mensal
Alvo Fase 2: < 15% mensal
Industry average: 5-10% (para SaaS health)
```

### Retention Curve

```
D7 = % usuários que voltam dentro de 7 dias
D30 = % usuários que voltam dentro de 30 dias
D90 = % usuários que voltam dentro de 90 dias

Alvo AquariOS:
D7: 70%
D30: 50%
D90: 40%
```
