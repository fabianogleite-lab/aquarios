Politica de Privacidade — AquariOS

Ultima atualizacao: 22 de maio de 2026

A Arkhe ("nos") opera o aplicativo AquariOS. Esta politica descreve como coletamos, usamos e protegemos seus dados pessoais, em conformidade com a Lei Geral de Protecao de Dados (LGPD — Lei 13.709/2018).

1. Dados Coletados

  • Dados de conta: e-mail e senha (para autenticacao)
  • Dados de uso: registros no diario pessoal, dados nutricionais, preferencias do app
  • Conversas com IA: mensagens trocadas com o assistente ProteOS (para contexto da conversa)
  • Dados tecnicos: tipo de dispositivo, versao do sistema operacional (para compatibilidade)

2. Finalidade do Tratamento

  • Fornecer e melhorar os servicos do aplicativo
  • Personalizar a experiencia do usuario
  • Manter o historico de conversas com o assistente IA
  • Garantir a seguranca da conta

3. Base Legal

O tratamento de dados pessoais e realizado com base no consentimento do usuario (Art. 7, I, LGPD) e na execucao de contrato (Art. 7, V, LGPD).

4. Armazenamento e Seguranca

  • Os dados sao armazenados no Supabase (infraestrutura PostgreSQL com criptografia em repouso)
  • Senhas sao armazenadas com hash seguro (bcrypt)
  • Comunicacao entre o app e os servidores e criptografada via HTTPS/TLS
  • Acesso aos dados e restrito a equipe tecnica autorizada

5. Compartilhamento de Dados

  • Anthropic: mensagens enviadas ao ProteOS sao processadas pela API Claude (Anthropic) para gerar respostas. A Anthropic nao armazena conversas apos o processamento.
  • Supabase: provedor de infraestrutura de banco de dados e autenticacao.
  • Nao vendemos, alugamos ou compartilhamos dados pessoais com terceiros para fins comerciais.

6. Direitos do Titular (LGPD Art. 18)

Voce tem direito a:

  • Confirmar a existencia de tratamento de seus dados
  • Acessar seus dados pessoais
  • Corrigir dados incompletos ou desatualizados
  • Solicitar a exclusao de seus dados
  • Revogar o consentimento a qualquer momento
  • Solicitar a portabilidade de seus dados

7. Retencao de Dados

Seus dados sao mantidos enquanto sua conta estiver ativa. Ao solicitar exclusao da conta, todos os dados pessoais serao removidos em ate 30 dias, exceto quando exigido por lei.

8. Menores de Idade

O AquariOS nao e direcionado a menores de 13 anos. Nao coletamos intencionalmente dados de criancas.

9. Alteracoes nesta Politica

Podemos atualizar esta politica periodicamente. Alteracoes significativas serao comunicadas pelo aplicativo.
