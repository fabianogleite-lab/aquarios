  QUICK START (COPY-PASTE READY)

STEP 1: Clone & Setup (5 minutes)
  $ git clone https://github.com/your-org/aquarios.git
  $ cd aquarios
  $ make setup

STEP 2: Start Development
  Terminal 1:
  $ make dev

  Terminal 2 (if working on frontend):
  $ cd frontend && npm start

STEP 3: Run Master Orchestrator
  $ make orchestrate           # Generate all configs
  $ make orchestrate-validate  # Validate files
  $ make orchestrate-export    # Export to JSON/YAML

STEP 4: Quality Checks (Before Committing)
  $ make quality     # format + lint + type-check + security
  $ make test        # run all tests
  $ make pre-commit  # full CI checks

STEP 5: Deploy
  Staging:
  $ git push origin staging

  Production (after approval):
  $ make deploy-prod
