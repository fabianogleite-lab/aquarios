## 🎭 Filosofia: por que Jornada do Herói

Joseph Campbell mostrou em *O Herói de Mil Faces* (1949) que **todas as culturas humanas contam a mesma narrativa essencial** sobre transformação pessoal. O AquariOS *é* essa jornada: o usuário sai da fragmentação (corpo+mente+espírito+finanças isolados), atravessa o limiar (free anônimo → trial), encontra mentores (ProteOS, comunidades, mentores B2B), enfrenta provas (hábitos, IVI baixo), e retorna integrado.

**Por que é a campanha certa para AquariOS:**
1. **Universal** — funciona em 14 países e 13 culturas sem precisar reinventar
2. **Não-medicalizada** — não promete curar, promete *jornada*
3. **Conecta com EcumenicOS** — toda tradição religiosa tem seu hero (Cristo, Buda, Krishna, Maomé, Zaratustra, Hércules...)
4. **Tempo de engajamento longo** — não é viral 30s, é narrativa de 30 dias

// data/heros_journey_pipeline.ts
export interface CountryCampaign {
  country_code: string;        // 'BR'
  locale: string;              // 'pt-BR'
  hero_persona: string;        // 'CARLOS_MENDES'
  hero_persona_id: UUID;       // FK personas
  stages: {
    press_release_a_published: boolean;
    press_release_a_url?: string;
    press_release_b_published: boolean;
    press_release_c_published: boolean;
    social_platforms_setup: SocialPlatform[];
    posts_scheduled: number;
    posts_published: number;
    followers_total: number;
    aderencia_pct: number;       // % visitas/conversões
  };
  primary_social: string;       // 'Instagram'
  secondary_social: string;     // 'WhatsApp'
  press_outlets: string[];      // ['Folha', 'UOL', 'G1']
  launch_date: Date;
  status: 'planning' | 'pre_launch' | 'active' | 'mid_journey' | 'complete';
}

export type SocialPlatform =
  | 'instagram' | 'whatsapp' | 'telegram' | 'line' | 'kakaotalk'
  | 'wechat' | 'facebook' | 'tiktok' | 'twitter' | 'linkedin' | 'snapchat';

### Tabela SQL (migration 14 futuro)

```sql
CREATE TABLE heros_journey_campaigns (
  id                      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  country_code            TEXT NOT NULL UNIQUE,
  locale                  TEXT NOT NULL,
  hero_persona_id         UUID REFERENCES personas(id),
  hero_persona_code       TEXT,
  primary_social          TEXT,
  secondary_social        TEXT,
  press_outlets           TEXT[],
  campaign_status         TEXT DEFAULT 'planning'
    CHECK (campaign_status IN ('planning','pre_launch','active','mid_journey','complete')),
  launch_date             DATE,
  press_release_a_url     TEXT,
  press_release_b_url     TEXT,
  press_release_c_url     TEXT,
  social_setup            JSONB DEFAULT '{}'::jsonb,
  metrics                 JSONB DEFAULT '{}'::jsonb,
  notes                   TEXT,
  created_at              TIMESTAMPTZ DEFAULT now(),
  updated_at              TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE campaign_posts (
  id                      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  campaign_id             UUID REFERENCES heros_journey_campaigns(id),
  platform                TEXT NOT NULL,
  scheduled_for           TIMESTAMPTZ,
  published_at            TIMESTAMPTZ,
  content                 TEXT,
  hero_stage              SMALLINT CHECK (hero_stage BETWEEN 1 AND 12),
  metrics                 JSONB,
  created_at              TIMESTAMPTZ DEFAULT now()
);
```
