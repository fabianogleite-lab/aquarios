## 🚀 Quick Start (Copy-Paste Ready)

### 1. Clone & Setup (5 minutes)

```bash
git clone https://github.com/your-org/aquarios.git
cd aquarios
make setup
```

### 2. Start Development

```bash
make dev        # Terminal 1: Python API
cd frontend && npm start  # Terminal 2: React (if working on UI)
```

### 3. Run Master Orchestrator

```bash
# Generate all configurations
make orchestrate

# Validate everything
make orchestrate-validate

# Export to JSON/YAML/HTML
make orchestrate-export
```

### 4. Run Tests & Quality Checks

```bash
make quality    # format + lint + type-check + security
make test       # all tests
make test-coverage  # with coverage report
```

### 5. Deploy

```bash
# Staging (automatic via GitHub Actions)
git push origin staging

# Production (after approval)
make deploy-prod
```

## 🔄 CI/CD Pipeline (Automated)

### On `git push`:

1. **Linting** (flake8, pylint, black)
2. **Type Checking** (mypy)
3. **Security Scan** (bandit, trivy)
4. **Unit Tests** (pytest)
5. **Integration Tests** (with PostgreSQL + Redis)
6. **Build Docker Image** (multi-stage, pushed to registry)
7. **Deploy to Staging** (if `staging` branch)
8. **Deploy to Production** (if `main` branch + approval)
9. **Slack Notification** (result)
